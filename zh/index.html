功能描述

交付结果

将 AI 客服从单纯知识问答扩展为可挂载、可转人工、可接业务且可治理的运行时能力，降低宿主系统改造成本。

RAG-QA System

企业知识问答系统，覆盖多源文档接入、知识治理与答案引用依据。

内容定位

企业知识问答系统，覆盖多源文档接入、知识治理与答案引用依据。

功能描述
  • 设计结构检索、全文检索、向量检索三路召回链路，结合加权 RRF 融合与 rerank，支持 citations、grounding_score 与 trace_id 返回。

交付结果

将企业分散资料沉淀为可持续同步、可追溯引用、可配置 Agent 能力的 AI 问答平台，降低检索、答复、治理和后续集成成本。

  • 设计结构检索、全文检索、向量检索三路召回链路，结合加权 RRF 融合与 rerank，支持 citations、grounding_score 与 trace_id 返回。

微信机器人 / 分层记忆 / 长期运行

微信智能助手

面向 Windows 微信生态的微信机器人项目，支持长期运行、自动回复与运行治理。

内容定位

面向 Windows 微信生态的微信机器人项目，支持长期运行、自动回复与运行治理。

功能描述
  • 抽象 BaseTransport 接入层并以 LangGraph 重构回复主链，将同步回复与后台成长任务解耦，建立适合长期运行的微信助手架构。
  • 构建 SQLite 短期记忆、运行期向量记忆与导出语料 RAG 三层记忆体系，支持轻量重排与可选本地 Cross-Encoder 自动回退，平衡召回质量与部署成本。
技术描述

技术实现重点在 BaseTransport 接入边界、LangGraph 运行时、轻量重排与可选本地 Cross-Encoder 回退、配置快照/热重载以及 /api/status、/api/metrics、成本接口的协同。

交付结果

将微信自动回复脚本升级为具备接入治理、运行诊断与成本分析能力的桌面智能助手，降低长期运行和排障成本。

  • 抽象 BaseTransport 接入层并以 LangGraph 重构回复主链，将同步回复与后台成长任务解耦，建立适合长期运行的微信助手架构。
  • 构建 SQLite 短期记忆、运行期向量记忆与导出语料 RAG 三层记忆体系，支持轻量重排与可选本地 Cross-Encoder 自动回退，平衡召回质量与部署成本。

EasyCloudPan

面向团队内部部署的企业级文件平台，覆盖认证、分享、回收站、预览和运维入口。

内容定位

面向团队内部部署的企业级文件平台，覆盖认证、分享、回收站、预览和运维入口。

功能描述
  • 构建“分片上传 + 秒传 + 断点续传 + SSE 状态回传”主链路，结合零拷贝分片合并，支持 1000+ 并发上传，成功率 >99.5%（README 指标口径）。
  • 完成 PostgreSQL 复合索引、游标分页与 Caffeine / Redis 多级缓存治理，使 API P95 <500ms、P99 <1s、数据库查询 P95 <100ms，慢查询减少 80%（README 指标口径）。
技术描述

技术实现重点放在上传主链路、零拷贝合并、PostgreSQL 索引与游标分页、Redis/Caffeine 多级缓存、签名防重放和可观测体系的整体配合。

交付结果

提供可私有化部署的文件协作底座，兼顾高并发上传、安全治理、身份接入扩展与监控验收能力。
